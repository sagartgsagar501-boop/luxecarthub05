# LuxeCart Hub

This is a static website project for the LuxeCart Hub affiliate store.

## Files
- `index.html` - home page
- `admin.html` - admin panel for local product editing
- `style.css` - styles
- `products.json` - product data

## Publish on GitHub Pages
1. Create a GitHub account at https://github.com.
2. Create a new repository, for example `luxecart-hub`.
3. Add this project to the repo.
4. In GitHub repository `Settings` > `Pages`, choose the `main` branch and `/ (root)` folder.
5. Save and open the provided URL.

## Local git setup
Run this in the project folder:

```bash
git init
git add .
git commit -m "Initial site commit"
```

## Push to GitHub
After creating the repo on GitHub, run:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git branch -M main
git push -u origin main
```
